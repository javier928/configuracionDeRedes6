English: 
Program that reads 3 dbf files in order (pretending it is an ebook and each dbf file contains a page of the ebook).
All files must be in the C:\DBASE folder in order to be executed properly.

Español:
Programa que lee tres archivos dbf (para crear un ebook. Cada fichero dbf contiene una pagina de
ebook).
Todos los archivos deben estar en la carpeta C:\DBASE.

Descargue el ebook ConfiguracionDeRedes.PDF para mas información
